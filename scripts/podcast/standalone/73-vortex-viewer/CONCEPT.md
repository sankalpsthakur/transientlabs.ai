# Episode73 — Vortex viewer

An invented optical viewer maps the Burgers-vortex balance onto a circular window: the Gaussian core contracts under imposed strain and spreads under viscous diffusion, while two fixed-scale dials report core radius and peak vorticity. A radial sample marker probes the same field. The observer sees one cross-section, not a bounded laboratory fluid solution.

Model: prescribed axisymmetric linear strain u_r=−ar/2,u_z=az and Gaussian axial vorticity ω(r,t)=Γ/(πq(t)) exp(−r²/q(t)), q=w². Initial w0=8mm, fixed Γ=1000mm²/s. The positive-viscosity Gaussian ansatz obeys q′=4ν−aq. For a>0, q=q0 exp(−at)+(4ν/a)(1−exp(−at)); for a=0, q=q0+4νt. Controls: a=0–2s⁻¹,ν=.5–8mm²/s,t=0–10s,probe radius0–24mm. The core radius is the1/e-vorticity radius, not a rigid wall. Equilibrium radius exists only for a>0. Every displayed reading, radius contour and probe coordinate uses this one model.

The field is finite for all displayed positive ν and constant finite a. It does not prove global regularity of general Navier–Stokes. The imposed strain is not produced by the vortex, and its velocity grows without bound at infinity; this infinite-energy family is outside Clay's finite-energy problem. The window truncates the infinite plane at24mm; a displayed circulation fraction accounts for the clipped tails. Shading is normalized to the current peak, while the peak dial has a fixed0–350s⁻¹ range. Changes to a orν select another trajectory from the same initial profile, without solving a switched-boundary apparatus. No turbulence, instability, forcing claim or full3D solver is added.
